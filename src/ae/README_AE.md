# 巨石营救 · After Effects 工程导出说明

## 使用步骤
1. 网页工具中点「▶ 自动通关」（自动开始记录），或在面板「导出 AE 工程」里点「● 开始记录」后手动游玩；完成后点「■ 停止并导出」/「⬇ 导出 ZIP」，得到 `boulder_ae_export_*.zip`。开启「录制视频时同步记录，停止录制后自动导出」时，停止视频录制会自动导出。
2. 解压到任意文件夹（保持 `build_ae_project.jsx`、`timeline.json`、`assets/`、`audio/` 在同一目录）。
3. After Effects（CC 2018 及以上）→ 文件 → 脚本 → 运行脚本文件… 选择 `build_ae_project.jsx`。脚本按自身位置查找素材，不需要改路径。
4. 脚本新建工程、导入素材、建立「主合成_巨石营救」（尺寸=「AE 合成尺寸」，帧率=「AE 合成帧率」），完成后弹出统计（图层数 / 关键帧数 / 标记数），并询问是否**另存为 .aep**（「脚本跑完后提示另存为 .aep」）。

> 如果提示“脚本没有写入文件的权限”：在 编辑 > 首选项 > 脚本和表达式 勾选 **允许脚本写入文件和访问网络**。只影响最后一步保存 .aep。

## 文件
| 路径 | 内容 |
|---|---|
| `build_ae_project.jsx` | 构建脚本 |
| `timeline.json` | 时间轴（meta / folders / assets / comps / mainComp） |
| `assets/` | PNG 素材（英文文件名，AE 中显示名随「图层命名」中文/English） |
| `audio/` | `mix.wav` 混合音轨，`sfx_*.wav` 每种音效单独一份 |
| `README_AE.md` | 本说明 |

## 图层结构（从下到上）
- 背景：地牢砖井、火把光、酸液池远景
- 酸液 / 气泡：池面与上升气泡（循环缩放/位移）
- 棋盘：木板框架与螺丝孔位；悬石、平台、绞盘、配重、绳索等矿坑机关
- 木板_N：每个木格横/竖条一层；螺丝拆完时位置/旋转/不透明度关键帧坠落
- 螺丝_NN_颜色：42 颗六色螺丝各一层；拔出时沿弧线飞向托盘，三消时放大淡出
- 被困角色：影子 / 双腿 / 身体 / 双臂 / 头（害怕、开心、眩晕三种头贴图），第一幕护脸、第二幕抓绳，随平台上升、庆祝或失败摇晃
- 托盘：粉色三槽托盘；消除时抖动（位置关键帧）；槽内螺丝由对应 `螺丝_NN` 图层延续
- 计时环 / 指针 / 数字：倒计时与加时飘字
- 提示光环 / 三消光环 / 粒子：闲置提示、消除爆点、火花与粉尘
- 顶部字幕、底部免责声明（若开启）
- 结束页（若开启）：原创黑猫整屏结束卡 + 无需下载/点击即玩哦文案；结束页手指可选
- 手指：默认参考视频同款白手套（Canvas），可切换麻将工具同款手；锚点 = 指尖，位置 + 按下缩放
- 混合音轨 / 音效_逐事件（预合成，每个音效一层放在发生时刻）；主合成每个音效事件一个标记（按下 / 入槽 / 三消 / 木板坠落 / 落石 / 滴答 / 通关 / 失败）。

图层严格按时间轴从下到上排列，与网页 Canvas 的 `z` 排序一致；每个 Sprite 的素材、位置、缩放、旋转、不透明度均逐帧采样，默认「精简」为线性关键帧（误差 <0.3px），可切换「逐帧烘焙」。

## 说明
- 图层命名可选中文/English（「图层命名」），与麻将工具同一规范（见 `ref/TOOLKIT_STANDARD.md`）。
- 网页画面本身就是由同一组精灵（素材 + 位置/缩放/旋转/不透明度）绘制的，导出的 AE 合成与网页逐像素一致（`npm run test:ae` 校验 PSNR）。
- 结束页与免责声明使用固定层名「结束页 / End card」「免责声明 / Disclaimer」「背景 / Background」「手指 / Hand」，方便自动化与模板替换。
- 如果记录后修改了画布/外观参数，请重新开始一局再导出。
- 3D 导出复用同一份记录，见 3D ZIP 中的 `README_3D.md`。
