# 参考广告分析（内部）

## 声明

本项目参考了一支投放用的拯救/拆螺丝类竖屏广告，用于研究玩法节奏、镜头构图与美术方向。**参考视频及其逐帧截图仅用于内部设计分析，未存入本仓库、未上传 GitHub、未打进任何导出包。** 本文不记录原视频链接与品牌信息。仓库中的截图全部由本工具自行渲染。

因此该文件是设计说明，不是素材分发：不含参考帧、不含参考广告的 Logo、角色、文案或商标。

## 参考结构

竖屏 9:16（工具画布 720×1280），单指点击，核心叙事是“拆掉障碍 → 救出被困者”。

1. **开场**：矿坑剖面。砖墙与暗角压住四周，底部酸液池冒泡，矿工被巨石压在中央平台上，木板与螺丝封住出口。
2. **交互**：手指点击螺丝，螺丝旋出飞向托盘；三颗同色自动消除；木板失去两端螺丝后坠落；平台随进度上升。
3. **压力**：右上角倒计时环；托盘槽位有限，异色塞满即失败；三消加时给出正反馈。
4. **高潮**：全部螺丝拆除，木板连续塌落，巨石升起，矿工获救，光效与金色粒子爆发。
5. **结束卡**：全屏 CTA。参考的结束卡角色与品牌素材没有复用，本工具改为原创矿坑救援插画。

## 有意的差异

- **结束页**：完全重绘，不使用参考广告中的黑猫/品牌结束卡，避免第三方素材进入公开仓库与 H5 包。
- **手指**：按用户要求使用麻将消除工具的同款手 + 指尖触控笔，而不是参考广告中的白色手套。
- **文案**：默认中文（字幕“拆光螺丝 救出矿工”）可在面板中修改；工具不绑定任何品牌。
- **编辑器**：参考广告是成片，本工具是可调参的制作工具；右侧面板与所有导出能力不属于参考画面。
