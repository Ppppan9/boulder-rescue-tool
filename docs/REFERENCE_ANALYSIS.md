# 参考广告分析（内部）

## 声明

本项目参考了一支投放用的拯救/拆螺丝类竖屏广告，用于研究玩法节奏、镜头构图与美术方向。**参考视频及其逐帧截图仅用于内部设计分析，未存入本仓库、未上传 GitHub、未打进任何导出包。** 本文不记录原视频链接与品牌信息。仓库中的截图全部由本工具自行渲染。

因此该文件是设计说明，不是素材分发：不含参考帧、不含参考广告的 Logo、角色原图、文案原文或商标。

## 参考结构

竖屏 9:16（工具画布 720×1280），单指点击，核心叙事是“拆掉障碍 → 救出被困者”。参考片约 59 秒，包含两幕与一张结束卡：

1. **第一幕 · 蓝石矿坑**：蓝灰色卵石填满上半屏，右侧石壁挖出人质壁龛；金发、白色矿工帽、红短裤的年轻男子双手护脸躲在壁龛里，一根粗木梁从上方斜压下来。粉色三槽托盘嵌在石台中，下方是 7 列木格螺丝棋盘（42 颗、六色十字螺丝）。计时气泡在第一次点击后出现，从 22 秒开始倒数；三消不额外加时。
2. **交互**：白色卡通手套从右下方伸出，点击螺丝后螺丝飞入托盘；三颗同色自动消除，托盘会随当前颜色泛光；木板失去两端螺丝后坠落，露出后面的砖墙 / 蓝石。
3. **失败**：时间耗尽或托盘塞满时，场景高斯模糊，正中央弹出白边粉色 FAIL 圆徽章。
4. **第二幕 · 酸池地牢**：同一男子被绳子绑住，站在石台上，手握绳索经左侧滑轮连到下方；左侧是绿色酸池，棋盘变成 6 列 × 7 行，棋盘后是蓝石堆与砖墙，这一幕没有计时器。
5. **结束卡**：浅色摄影棚里的黑色小猫，大而圆的黄色眼睛，抬起一只粉爪；右上方橙色“无需下载”与白色“点击即玩哦”，底部广告合规小字。

## 有意的差异

- **结束页黑猫**：参考视频里的黑猫照片是第三方素材，未复用。本工具用 ImageGen 生成了一只构图相近的**原创黑猫**，再叠加“无需下载 / 点击即玩哦”文案，避免把参考照片打进仓库或 H5 包。
- **白手套**：按参考视频绘制为 Canvas 白手套（默认）；用户此前要求的麻将工具同款手仍保留为可切换素材。
- **玩法结局**：参考视频是剪辑过的失败广告（两次 FAIL 后接结束卡）；本工具是可玩的制作工具，默认可自动通关，失败时才会出现 FAIL 演出，不会强制播放失败脚本。
- **文案/免责声明**：默认字幕对齐视频钩子，可在面板修改；底部使用工具自己的“广告创意演示”免责声明，不复刻参考片的平台审核文字。
- **编辑器**：参考广告是成片，本工具是可调参的制作工具；右侧面板与所有导出能力不属于参考画面。
